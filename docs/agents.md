# Agents

Behind the skills, three agents each do one job. A skill asks an agent when it
needs that job done; you don't run one yourself. The messenger is the one that
talks to you. The estimator and the shopper hand their answers back to the skill
that asked.

## The messenger

The messenger writes and sends your reminders, with one question in mind: what
will make you actually read this one? It writes each message in the style you
set up, takes its tone from the day, and sends it the way you chose to be
notified. It has no fixed shape, because the same message every day stops
getting read.

A reminder reads the same whether a job sends it on schedule or you run it by
hand.

## The estimator

The estimator works out how big each task is, on your own scale, and whether you
could do all of it in one go after a workday. When you review your task list
with ntm, it proposes each task's estimate and you decide. It learns from what
you decide and correct, so its guesses get closer to yours over time.

Planning leans on its estimates to pick tasks that fit your day.

## The shopper

The shopper checks one thing you're watching to buy: is it a good deal today? It
looks across stores you'd trust, checks today's price on each store's own page,
and notes what it found on the task.

The daily price watch asks a shopper about each item you're watching, then tells
you about the deals.
