# ntm:help

Answers the user's questions about ntm from its README.

## Setup

Read `README.md` in the newest installed `ntm`.

## Usage

```
/ntm:help [<question in words>]
```

With nothing after it, give the README's opening paragraph and its First steps.
For this usage, treat this skill similarly to a man page. Help the user learn
about ntm.

## Answering

Answer from the part of the README that covers the question, in a few sentences
of prose.

When the README doesn't answer it, say so, and name the skill in its Skills list
that covers it, if one does.
