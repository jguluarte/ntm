# The completed facts

The completed facts, in place of today's open items, each task written as the
skill's The facts says:

- `span: <first day> to <last day>`
- `done:` one line per item done in the span, oldest first, or `done: none`.

Ask `ntm-user:backend` for the items done in the span. This reminder is always
sent, `done: none` included.
