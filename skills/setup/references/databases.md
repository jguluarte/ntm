# Databases

Setup's databases step. Confirms the names of the databases the user's features
need. It creates none.

## The names

Show the names in one short list, each with what it holds in a few words, from
its entry under Databases in `rules/core.md` and in the rules of each feature
they picked. Show the ones already made as done, under the names they have.

A simple affirmation keeps every name. For the databases still to be created,
record any other name they give, such as a document they already keep under
another title, for the build, which writes where each document lives into
`ntm-user:backend`.

### `%Price-watch-stores`

In the same line, say they can name a few stores they trust, by category with
their domains; record them for the build, as the Seed list for the database's
first write.
