# Update notes

One note per version of ntm, named for the version, such as `0.5.0.md`.
`ntm:update` follows each note newer than the user's version, oldest first.

```
Needs the user: <yes or no>

## What's new

<The changelog, for the user, in plain words.>

## For ntm:update

<What to do, step by step, for a user coming from an older version.>

Rebuild ntm-user: <yes or no>
```

Needs the user is yes when following the note needs the user to answer questions
or install something. A note that rebuilds `ntm-user` always does.
